# 后续步骤

-----

## 深入学习

到此为止，你应该已经掌握了 Hatch 的基础用法。

接下来你可以进一步了解 [环境](config/environment/overview.md) 或 [构建](config/build.md) 的高级配置，设置你偏好的 [交互式 shell](config/hatch.md#shell)，或阅读更多关于 Hatch 的 [命令行工具](cli/about.md)。

之后，不妨看看 [Hatch Showcase](https://github.com/ofek/hatch-showcase) 项目，从中了解 Hatch 的更多可能性。

最后，如果你有相关需求，也可以编写一个 [插件](plugins/about.md) 来扩展功能。
